# 重複トピック管理

類似テーマの記事が複数存在する場合に記録。重複を避け、記事の独自性を確保するため。

---

## フォーマット

```markdown
## トピック名

- 記事ID: タイトル / 切り口
- 記事ID: タイトル / 切り口

### 差別化ポイント
- 検索意図の違い（情報収集 / 比較検討 / 行動）
- ターゲット読者の違い（健診後 vs 服薬中 など）
- 切り口の違い（症状 / 治療 / 予防）
```

---

## 注意：絶対に避ける重複パターン

- 「新横浜」「港北区」「横浜市」だけを差し替えた量産記事
- 同じ症状・同じ切り口で表現だけ変えた記事
- タイトルだけ変えて中身が同じ記事
