# 医療広告ガイドラインチェックリスト

厚生労働省「医業若しくは歯科医業又は病院若しくは診療所に関する広告等に関する指針」に基づく。

---

## 禁止表現チェック

### 1. 比較優良広告
- [ ] 「日本一」「No.1」「最高」「地域一番」などの最上級表現がない
- [ ] 他院との比較で優劣をつけていない
- [ ] 「特別」「トップクラス」「最先端」などの優位性を示す表現がない

### 2. 誇大広告
- [ ] 「絶対安全」「100%治る」「完全に消える」などの断定がない
- [ ] 「副作用なし」「リスクゼロ」がない
- [ ] 効果効能の保証表現がない
- [ ] 「画期的」「革新的」など効果を過剰にうたう表現がない

### 3. 体験談・ビフォーアフター
- [ ] 患者の主観的体験談を効果効能の根拠として使っていない
- [ ] ビフォーアフター画像には適切な説明（治療内容・費用・リスク・副作用）を併記
- [ ] 個人特定可能な情報を含んでいない

### 4. 公序良俗違反
- [ ] わいせつな表現がない
- [ ] 不安をあおる表現がない（「放置すると死に至る」など）

### 5. 自由診療・美容医療（限定解除要件）
- [ ] 通常必要となる治療内容を明示
- [ ] 標準的な費用を明示
- [ ] 主なリスク・副作用を明示
- [ ] 治療効果には個人差があることを明記
- [ ] 未承認医薬品・機器の場合はその旨を明示

## 表現の言い換え集

| NG表現 | OK表現 |
|--------|--------|
| 必ず治る | 改善が期待できます／改善する方が多くいらっしゃいます |
| 絶対安全 | 比較的安全性の高い治療です／重篤な副作用は稀です |
| 完全に消える | 目立たなくなることがあります |
| 副作用なし | 重い副作用は報告されていません |
| 最高の○○ | ○○に注力しています |
| No.1 | 記載しない（または客観的根拠を併記） |
| 特別な技術 | ○○の経験があります |
| 最先端の治療 | 比較的新しい治療法です |
| 痛みゼロ | 痛みを抑える工夫をしています |
| 短期間で効果 | 個人差はありますが、効果を実感される方もいます |

---

## 美容医療・自由診療の必須記載事項

### 共通
- 自由診療である旨
- 治療内容の詳細
- 標準的な費用
- 主なリスク・副作用
- 効果には個人差があること

### 未承認薬・機器使用の場合
- 未承認である旨
- 入手経路
- 国内承認医薬品との違い
- 諸外国での承認状況
- 重篤な副作用報告の有無
